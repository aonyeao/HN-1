INDEPENDENT FRAME 独立电影工作室｜作品集网站

打开方式
1. 双击 index.html 即可在浏览器中打开。
2. 网站素材全部位于 assets 文件夹，请勿单独移动 index.html。
3. 页面中的图片可点击放大；动态影像区点击播放按钮观看视频。
4. 右上角“静音浏览”可统一切换影片声音。

项目结构
- index.html：网站页面
- styles.css：视觉与响应式样式
- script.js：图片放大、视频播放、声音控制和滚动动效
- assets：17张项目效果图与2段影片

视觉方向
作者电影 / 胶片编辑感
主色：胶片黑、放映白、丝绒绿、暗房红、木质棕
署名：香榭电影工作室
